# GiftTracker — правила работы с локальным рантаймом

> Прочитай до любых действий с процессами. Нарушение этих правил уже приводило
> к «бесконечным» рестартам: две сессии по очереди убивали процессы друг друга.

## Главное правило: один владелец

Локальный рантайм (API + туннель + бот) обслуживает **только одна сессия**.
Если открыт второй чат — он не должен трогать процессы. Если нужно передать
управление — сначала закрой старую сессию, потом работай в новой.

## Чем управлять НЕЛЬЗЯ

- Никаких `Stop-Process -Id <pid>` по спискам процессов.
- Никаких циклов «нашёл python/ssh → убил → запустил → подождал 45с → проверил».
- Никаких проверок папки `Startup`, планировщика, автозапуска — их там нет.
- Не перезапускать то, что уже работает. Рестарт туннеля меняет URL и требует
  рестарта бота — это каскад, а не «починка».

## Единственный разрешённый способ

```powershell
cd C:\Users\Нико\.zcode\workspace\f7dd6fd0-2717-4a02-88bb-95556b60b317\gift_tracker
powershell -ExecutionPolicy Bypass -File .\start_local.ps1
```

Скрипт идемпотентный: проверяет здоровье и **лечит только сломанное**.

- API живой (pid один) → не трогает.
- `MINI_APP_URL` из `.env` отдаёт 200 и содержит `GIFTTRACKER` → туннель не трогает.
- Бот один, heartbeat свежий (<90с) и `mini_app_url` совпадает с `.env` → не трогает.
- Дубли бота/uvicorn → сам оставляет ровно один экземпляр.
- `-BotOnly` → перезапуск только бота (новый код без смены URL туннеля).
- `-Force` → полный рестарт (новый URL туннеля).

## Признаки здоровья

| Компонент | Проверка | Норма |
|---|---|---|
| API | `Invoke-RestMethod http://127.0.0.1:8020/api/health` | `status = ok` |
| Туннель | GET `MINI_APP_URL` из `.env` | HTTP 200, тело содержит `GIFTTRACKER` |
| Бот | `data/bot_heartbeat.json` | `status=ok`, `timestamp` моложе 90с |
| Бот | процесс `python -m bot.main` | ровно один |
| Тесты | `python -m pytest` | всё зелёное (сейчас 111) |

## Частые ошибки и что делать

- **`TelegramConflictError: terminated by other getUpdates request`** — работают
  две копии бота. Запусти `start_local.ps1`: он оставит одну. Не убивай PID вручную.
- **Туннель отдаёт 502** — агент умер. `start_local.ps1` сначала поднимает **tunnelmole**
  (HTTPS без браузерной заглушки), при неудаче — Serveo, затем обновляет `MINI_APP_URL`
  и перезапускает бота. Serveo в этой сети живёт ~20–50 минут; tunnelmole — основной вариант.
- **`MINI_APP_URL` устарел (старый домен)** — тот же скрипт.
- **Порт 8020 занят чужим процессом** — не убивай всё подряд; проверь
  `Get-NetTCPConnection -LocalPort 8020` и разберись, что это за процесс.
