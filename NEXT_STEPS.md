### Выполнено (этап 4 — надёжность)

- **Persistent-дедупликация**: таблица `seen_lots(url PRIMARY KEY, seen_at)` + `Database.claim_seen_lot()` (`INSERT ... ON CONFLICT DO NOTHING`). L1-кэш остался как быстрый фильтр. После рестарта бот не пушит те же лоты.
- **WAL checkpoint по расписанию**: `MaintenanceService` в боте и API, `PRAGMA wal_checkpoint(TRUNCATE)` каждые `WAL_CHECKPOINT_INTERVAL_SEC` + на старте/остановке. Очистка `seen_lots` старше `SEEN_LOTS_RETENTION_DAYS`.
- **Логи**: `bot/logging_setup.py`, уровень `LOG_LEVEL`, формат `LOG_FORMAT=text|json` (структурный JSON), логи uvicorn сведены к общему формату.
- **Heartbeat бота**: `bot/services/heartbeat.py` пишет `data/bot_heartbeat.json` (атомарно), `GET /api/health` отдаёт блок `bot{alive,age_sec,...}`, Docker healthcheck `python -m bot.healthcheck`, `stop_grace_period: 60s`.
- **Graceful shutdown**: отмена сканера и обслуживания, ожидание notifier, финальный heartbeat `stopped`, checkpoint WAL, закрытие БД.
- **Бэкап**: `scripts/backup_db.py` (sqlite3 backup API, ротация `--keep`, по умолчанию 7), раздел «Эксплуатация» в README.
- **Попутный фикс mock-лотов**: URL коллекции дополняется `#model=...&price=...`, иначе persistent-дедупликация по общему URL остановила бы demo-поток после первых лотов.
